# Vanilla item textures

`carrot.png`, `melon_slice.png`, `golden_carrot.png`, `glistering_melon.png`,
`sugar_cane.png`, `slime_ball.png`, `turtle_scute.png`, `gold_ingot.png` and
`bamboo.png` are unchanged 16×16 textures from Minecraft Java Edition 1.21.1.
The interface displays these native pixels with nearest-neighbor scaling.
`glistering_melon.png` is named `glistering_melon_slice.png` in the game.

Source: the official Mojang client archive:
https://piston-data.mojang.com/v1/objects/30c73b1c5da787909b2f73340419fdf13b9def88/client.jar

Archive SHA-1: `30c73b1c5da787909b2f73340419fdf13b9def88`.
Crafting quantities and patterns were read from `data/minecraft/recipe/` in
that archive. Minecraft assets belong to Mojang/Microsoft.
